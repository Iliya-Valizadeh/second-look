second‑look

Finds recurring charges, price rises, duplicates and odd spending in a bank or card statement.

Nothing leaves your browser

This page reads the file you choose on your own device and runs the same second-look Python package inside your browser, using Pyodide. No statement, row or byte of it is ever sent anywhere. There is no upload button and no server that could receive one.

How this page proves it, not just says it
  • The Content-Security-Policy this page sets blocks any request this page's own code could try to make to another origin. Its exact, current value:

  • A test in this project's continuous integration loads this page, runs it against a made-up statement, and fails the build if the page makes any request to another origin, a request that is not a plain GET, or a request outside a fixed list of this site's own files.
  • The source code for this page and for the exact rules it runs is public: github.com/Iliya-Valizadeh/second-look.
